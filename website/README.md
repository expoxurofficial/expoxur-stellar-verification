# \# Expoxur®

# 

# Expoxur® is a city-by-city discovery and credibility platform for impact-driven Filipino MSMEs and City Impact Enterprises (CIEs).

# 

# This directory contains the frontend codebase for the Expoxur® website included in the public Stellar verification repository for integration context.

# 

# \## Current Stack

# 

# \- React

# \- TypeScript

# \- Vite

# \- Tailwind CSS

# \- shadcn/ui

# 

# \## Project Structure

# 

# \- `src/pages/` — application pages

# \- `src/components/` — reusable interface components

# \- `src/assets/` — Expoxur® brand and CIEcat assets

# \- `public/` — public static files

# 

# \## Development

# 

# Install dependencies:

# 

# `npm install`

# 

# Run locally:

# 

# `npm run dev`

# 

# Build for production:

# 

# `npm run build`

# 

# \## Stellar Integration

# 

# The Stellar verification proof-of-concept is maintained alongside this website code under `../expoxur-stellar/`.
